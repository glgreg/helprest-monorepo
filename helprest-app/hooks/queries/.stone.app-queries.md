# App Queries (`helprest-app/hooks/queries`)

## Purpose and Design Decisions

Provides TanStack Query v5 (`@tanstack/react-query`) hooks that manage server-state caching, background refetching, and optimistic UI updates between `app-services` and `app-routing` screens.

## Invariants

- **Optimistic Favorite Toggling (`useFavorites.ts`)**: `removeFavorite` optimistically filters the target `referenceId` out of `["favorites"]` cache in `onMutate`, rolls back to `context.previous` in `onError`, and invalidates `["favorites"]` in `onSettled`.
- **Authenticated Favorites Contract (`useFavorites.ts`)**: Queries `GET /api/favorites` (`staleTime: 5 minutes`) and mutates via `POST /api/favorites` (`{ referenceId, type: "establishment" | "product" }`) and `DELETE /api/favorites/:id` with `authenticated: true`.

## Integration Contracts

- **`useFavorites()`**: Returns `{ favorites: { establishments, products }, isLoading, isFavorite(id, type), toggleFavorite(id, type) }`.
- **`useLocationQuery()` / `usePlacesQuery()`**: Query wrappers for device coordinates and establishment listings.

## Anti-Patterns

- Mutating favorites via raw `api.post("/api/favorites")` in UI components without invalidating the `["favorites"]` query key.
