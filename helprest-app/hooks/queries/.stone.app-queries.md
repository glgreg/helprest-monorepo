# App Queries (`helprest-app/hooks/queries`)

## Purpose and Design Decisions

Provides strictly typed TanStack Query v5 (`@tanstack/react-query`) hooks that manage server-state caching, background refetching, and optimistic UI updates between `app-services` and `app-routing` screens. All cache keys are sourced from the centralized `queryKeys` factory (`constants/queryKeys.ts`) covering `user`, `establishments`, `products`, `flags`, `visits`, `favorites`, and `location`.

## Invariants

- **Centralized Cache Keys (`constants/queryKeys.ts`)**: Query hooks and UI invalidations must use `queryKeys.*` (e.g., `queryKeys.favorites.all`, `queryKeys.establishments.all`, `queryKeys.location.byAddress(address)`) rather than ad-hoc string arrays.
- **Optimistic Favorite Toggling (`useFavorites.ts`)**: `removeFavorite` optimistically filters the target `referenceId` out of `queryKeys.favorites.all` cache in `onMutate`, rolls back to `context.previous` in `onError`, and invalidates `queryKeys.favorites.all` in `onSettled`.
- **Authenticated Favorites Contract (`useFavorites.ts`)**: Queries `GET /api/favorites` (`staleTime: 5 minutes`) and mutates via `POST /api/favorites` (`{ referenceId, type: "establishment" | "product" }`) and `DELETE /api/favorites/:id` with `authenticated: true`.

## Integration Contracts

- **`constants/queryKeys.ts`**: Hierarchical read-only `queryKeys` factory for `user`, `establishments`, `products`, `flags`, `visits`, `favorites`, and `location`.
- **`useFavorites()`**: Returns `{ favorites: { establishments, products }, isLoading, isFavorite(id, type), toggleFavorite(id, type) }`.
- **`useLocationQuery(address)` / `usePlacesQuery()`**: Typed TypeScript hooks (`useLocationQuery.ts`, `usePlacesQuery.ts`) querying Nominatim geocoding and `GET /api/establishments?page=1&limit=50`.

## Anti-Patterns

- Using raw string array query keys (`["favorites"]`, `["establishments"]`) in screens or hooks instead of `queryKeys` from `constants/queryKeys.ts`.
- Mutating favorites via raw `api.post("/api/favorites")` in UI components without invalidating `queryKeys.favorites.all`.
