# App Services (`helprest-app/services`)

## Purpose and Design Decisions

Centralizes all external device and network integrations for the mobile client: HTTP communication with `helprest-api` (`api.ts`), native Google OAuth2 sign-in via `@react-native-google-signin/google-signin` (`auth.ts`), and foreground/background GPS tracking plus Haversine distance calculation via `expo-location` and `expo-task-manager` (`location.ts`).

## Invariants

- **Fail-Fast Authenticated Requests (`api.ts`)**: When `authenticated: true` is passed to `api.get/post/patch/put/delete`, `loadTokens()` must return a valid `accessToken` or the client throws immediately before issuing a network call.
- **Single-Retry 401 Token Rotation (`api.ts`)**: On a `401` response for an `authenticated: true` request, `refreshAccessToken()` posts `{ refreshToken }` to `POST /api/auth/refresh`. If rotation succeeds, `saveTokens()` persists the new pair and the original request is retried once; if rotation fails, `clearTokens()` wipes the dead session.
- **Google OAuth Token Exchange (`auth.ts`)**: `signInWithGoogle()` obtains a native `idToken` (configured with `EXPO_PUBLIC_GOOGLE_OAUTH_CLIENT_ID`), exchanges it via `POST /api/auth/google`, and persists both the HelpRest JWT pair (`saveTokens`) and `GoogleUserInfo` (`saveGoogleUserInfo`) before returning `{ success, isNewUser, user }`.
- **Module-Scope Background Location Task (`location.ts`)**: `TaskManager.defineTask("HELPREST_BACKGROUND_LOCATION", ...)` must remain registered at top-level module scope outside React component lifecycles.

## Integration Contracts

- **`api.ts`**: `api.get<T>(path, options)`, `api.post<T>(path, options)`, `api.patch<T>(path, options)`, `api.put<T>(path, options)`, `api.delete<T>(path, options)` returning `Promise<{ data: T, status: number, ok: boolean }>`. Base URL defaults to `process.env.EXPO_PUBLIC_API_URL || "http://10.0.2.2:3000"`.
- **`auth.ts`**: `signInWithGoogle()` and `signOutGoogle()`.
- **`location.ts`**: `getCurrentPosition()`, `distanceBetween(a, b)`, `onLocationUpdate(cb)`, `startForegroundTracking()`, `stopForegroundTracking()`, `startBackgroundTracking()`, `stopBackgroundTracking()`.

## Anti-Patterns

- Calling `fetch()` directly against `helprest-api` from screens or hooks instead of going through `api` in `services/api.ts` (which bypasses Bearer injection and `401` token refresh).
- Logging out a user without calling `signOutGoogle()` when Google Sign-In was used, leaving the native Google session cached.
