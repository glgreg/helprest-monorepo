# API Domain (`helprest-api/src/domain`)

## Purpose and Design Decisions

This layer holds the core business model of HelpRest (`User`, `Establishment`, `Product`, `Flag`, `Visit`, `UserFavorite`), value objects (`Location`, `Rating`, `SocialLinks`), repository interfaces, and the pure `RecommendationService`. It has zero dependencies on HTTP, Redis, or infrastructure drivers (except `ObjectId` from `mongodb` for identity typing) so domain logic remains deterministic and unit-testable in isolation.

## Invariants

- **Immutability and Factory Construction**: All entities (`User`, `Establishment`, `Product`, `Flag`, `Visit`, `UserFavorite`) and value objects (`Location`, `Rating`, `SocialLinks`) have private constructors and freeze internal arrays (`Object.freeze([...props.flags])`). Instances are created via `static create()` (with validation) or hydrated via `static fromDocument()`.
- **State Transitions Return New Instances**: Updating an establishment's rating (`Establishment.withNewRating(visitRating)`) returns a new `Establishment` instance with recalculated `ratingCount`, `ratingTotal`, and rounded `rating` (`1` decimal place).
- **GeoJSON Coordinate Ordering**: `Location.toGeoJSON()` outputs `{ type: "Point", coordinates: [lng, lat] }` (longitude first per RFC 7946 / MongoDB `2dsphere` specification), whereas `LocationProps.coordinates` uses `{ lat, lng }`.
- **Auth Provider Invariant on `User`**: `User.create()` requires `passwordHash` when `authProvider === "local"` and `googleId` when `authProvider === "google"`. `role` defaults to `"user"` (`"user" | "establishment"`).
- **Recommendation Scoring Rules (`RecommendationService.rank`)**:
  - When a user has active dietary flags (`totalUserFlags > 0`) and an establishment matches **zero** of them (`matchCount === 0`), its score is forced to `0` and `SPONSOR_BONUS` (`0.05`) is ignored.
  - When `matchCount > 0`, `score = flagMatchRatio * 0.7 + proximityScore(distance) * 0.2 + (rating / 5) * 0.1 + (isSponsored ? 0.05 : 0)`, where `proximityScore` decays linearly from `1` at `0m` to `0` at `50,000m` (`50km`).
  - When `totalUserFlags === 0`, `score = proximityScore(distance) * 0.7 + (rating / 5) * 0.3 + (isSponsored ? 0.05 : 0)`.

## Integration Contracts

- **Entity Serialization**: Every entity exposes `static fromDocument(doc: Record<string, unknown>)` and `toDocument(): Record<string, unknown>` consumed by `api-infra` repositories.
- **Repository Interfaces**: `IUserRepository`, `IEstablishmentRepository`, `IFlagRepository`, `IVisitRepository`, and `IUserFavoriteRepository` define async persistence contracts injected into `api-application` use cases.
- **Geospatial Distance**: `RecommendationService.haversineDistance(lat1, lng1, lat2, lng2)` returns distance in meters and is shared with visit geofencing and social feed use cases.

## Anti-Patterns

- Importing `@infra/*`, `@interface/*`, or `process.env` inside `src/domain/`.
- Mutating entity fields or `flags` arrays in place instead of returning a new entity instance.
- Passing `[lat, lng]` instead of `[lng, lat]` into GeoJSON documents.
- Granting `SPONSOR_BONUS` to establishments with `0` matching dietary flags for a user who has dietary restrictions.
