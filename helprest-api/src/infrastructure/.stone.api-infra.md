# API Infrastructure (`helprest-api/src/infrastructure`)

## Purpose and Design Decisions

Provides concrete persistence, caching, and cryptographic implementations for `helprest-api`: native MongoDB v7 driver repositories (including `MongoAuditLogRepository`), startup index provisioning, lazy-connected Redis (`ioredis`) for caching and sliding-window rate limiting, and `jose` HS256 JWT token generation/verification. Using the official MongoDB driver without Mongoose avoids ODM overhead and gives direct control over `$geoNear` aggregation pipelines.

## Invariants

- **Required MongoDB Indexes (`createIndexes` in `database/mongodb/indexes.ts`)**:
  - `users`: unique index on `{ email: 1 }`.
  - `establishments`: `2dsphere` index on `{ "location.coordinates": "2dsphere" }` (required for `$geoNear`), `{ flags: 1 }`, `{ companyName: "text" }`, and `{ isSponsored: 1, rating: -1 }`.
  - `visits`: `{ userId: 1, date: -1 }` and `{ establishmentId: 1, date: -1 }`.
  - `flags`: `{ type: 1 }`.
- **Geospatial Queries (`MongoEstablishmentRepository.findNearby`)**: Uses MongoDB's `$geoNear` aggregation stage with `spherical: true`, `near: { type: "Point", coordinates: [lng, lat] }`, and `maxDistance` in meters.
- **JWT Lifetimes & Secrets (`security/jwt.ts`)**: Access tokens (`JWT_SECRET`, default `15m`) and refresh tokens (`JWT_REFRESH_SECRET`, default `7d`) use separate HMAC-SHA256 secrets, embed `role` claims, and enforce `issuer: "helprest-api"`.
- **Redis Graceful Degradation (`database/redis/connection.ts`, `cache/RedisCacheService.ts`)**: Redis uses `lazyConnect: true` and max 3 retries; cache misses or connection failures must log a warning and degrade gracefully without crashing the API process.

## Integration Contracts

- **Repositories**: `MongoUserRepository`, `MongoEstablishmentRepository`, `MongoFlagRepository`, `MongoVisitRepository`, `MongoProductRepository`, `MongoUserFavoriteRepository`, and `MongoAuditLogRepository` (`audit_logs` collection) are stateless and instantiated per module with constructor injection support for tests.
- **Security Helpers**: `generateTokens(payload)`, `verifyAccessToken(token)`, `verifyRefreshToken(token)`, and `checkRateLimit(key, config)` (`RATE_LIMITS.AUTH = 10/min`, `API = 100/min`, `SEARCH = 30/min`).

## Anti-Patterns

- Using `$near` without the `2dsphere` index on `location.coordinates` or passing `[lat, lng]` instead of `[lng, lat]`.
- Signing access and refresh tokens with the same secret (`JWT_SECRET` vs `JWT_REFRESH_SECRET`).
- Allowing a Redis connectivity error in `RedisCacheService` to fail an HTTP request when MongoDB is healthy.
